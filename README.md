# پورتفولیوی محدثه توکلی

وب‌سایت استاتیک فارسی با HTML، CSS و JavaScript خالص؛ مناسب انتشار رایگان روی GitHub Pages.

## ساختار

- `index.html` — محتوای صفحه، متادیتای SEO و ساختار معنایی
- `styles.css` — هویت بصری زیتونی، طلایی و کرم و طراحی واکنش‌گرا
- `script.js` — منوی موبایل، انیمیشن ورود و گالری پیش‌نمایش
- `img/` — تصاویر موجود پروژه‌ها در مخزن فعلی

## نکته درباره تصاویر

این نسخه از مسیرهای نسبی `img/...` استفاده می‌کند. هنگام جایگزینی فایل‌ها در مخزن فعلی، پوشه `img` موجود را حذف نکنید؛ تصاویر شخصی و تصاویر پروژه‌ها از قبل در همان مخزن قرار دارند. در صورت ساخت مخزن تازه، پوشه `img` را نیز از مخزن اصلی کپی کنید.

## اجرای محلی

هیچ Build یا وابستگی‌ای نیاز نیست. کافی است پوشه را با یک وب‌سرور استاتیک اجرا کنید؛ برای نمونه:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید. باز کردن مستقیم `index.html` نیز برای پیش‌نمایش ساده ممکن است.

## انتشار روی GitHub Pages

1. فایل‌های `index.html`، `styles.css` و `script.js` را در ریشه مخزن `mohadeseh-tavakoli.github.io` قرار دهید.
2. پوشه `img` فعلی را حفظ کنید.
3. تغییرات را روی شاخه `main` کامیت و Push کنید.
4. در GitHub به مسیر **Settings → Pages** بروید.
5. در بخش Build and deployment، گزینه **Deploy from a branch**، شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
6. پس از انتشار، سایت در نشانی GitHub Pages مخزن در دسترس خواهد بود.

## به‌روزرسانی محتوا

- متن‌ها و لینک‌ها را مستقیماً در `index.html` ویرایش کنید.
- رنگ‌ها در ابتدای `styles.css` به‌صورت CSS variables تعریف شده‌اند.
- برای اضافه‌کردن تصویر جدید، آن را در `img/` قرار دهید و مسیر نسبی آن را در HTML و در صورت نیاز در `imageMap` فایل `script.js` وارد کنید.

## نکات فنی

- راست‌چین و فارسی (`lang="fa"`, `dir="rtl"`)
- فونت Vazirmatn از Google Fonts با فونت‌های سیستمی جایگزین
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- تصاویر غیرضروری با `loading="lazy"`
- منوی موبایل با `aria-expanded` و کنترل صفحه‌کلید
- پیش‌نمایش تصاویر با عنصر بومی `dialog`
- پشتیبانی از `prefers-reduced-motion`
- فرم بک‌اندی یا دیتابیس ندارد؛ ارتباط از طریق ایمیل، تلفن و تلگرام است.

## شفافیت نمونه‌کارها

نسخه فعلی سایت مرجع چهار نمونه‌طراحی شخصی با نام و توضیح مشخص ثبت کرده است: آرام زیستن، ÉLORA، GLOWÉ و زرینه. در این نسخه پروژه پنجم حدس زده نشده است. اگر نام و شرح نمونه پنجم را تأیید کنید، می‌توان آن را به گالری اضافه کرد.
